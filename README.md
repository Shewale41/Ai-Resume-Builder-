# 🧠 AI Resume Builder

An intelligent, modern web application that helps users **create professional resumes effortlessly** using AI. Built with a **frontend UI**, **Strapi backend**, and smart automation, this project streamlines the resume-building process for job seekers, students, and professionals.

---

## 🚀 Features

- ✨ **AI-Powered Resume Generation** – Automatically generate tailored resumes based on user input.
- 🎨 **Modern Frontend** – Clean and responsive UI for a smooth user experience.
- ⚙️ **Strapi Backend** – Robust backend for managing resume data and templates.
- 🔍 **Real-Time Preview** – Instantly see how your resume looks while editing.
- 🌐 **Open Source** – Free to use, modify, and contribute.

---

## 📦 Tech Stack

- **Frontend:** JavaScript, CSS, HTML
- **Backend:** Strapi (Node.js)
- **Other:** AI-powered logic for resume generation

---

## 🛠️ Installation & Setup

Follow these steps to run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/Shewale41/Ai-Resume-Builder-.git

# 2. Navigate into the project directory
cd Ai-Resume-Builder-

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app should now be running locally on `http://localhost:3000`.
